# API Reference & Schemas

This directory will document the application programming interface (API) specifications, data contracts, and interaction schemas for **InsightPilot AI**, including:

- **REST / RPC Endpoint Definitions:** Endpoints for KPI queries, investigation triggers, driver decomposition, and recommendation requests.
- **Request / Response Contracts:** Pydantic / OpenAPI schema definitions for structured payloads.
- **Telemetry & Diagnostic Endpoints:** Health checks, runtime performance telemetry, and system audit logs.
- **Simulation Interfaces:** Parameterized simulation query and counterfactual response specifications.

> *Note: API endpoints and OpenAPI/Swagger documentation will be added during the backend and data foundation implementation steps.*
